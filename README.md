# Dinosaur Image Search

A web app that searches for images across public sources (Wikimedia Commons & Pixabay), similar to Google Image Search.

## Features

- Search images from multiple public sources
- Toggle sources on/off (Wikimedia Commons, Pixabay)
- Responsive image grid with hover effects
- Click to view full-size image in modal
- Dark theme UI
- No backend needed - runs entirely in the browser

## Usage

Open `index.html` in a browser. Type a search term and press Enter or click Search.
